# ARAM 아수라장 집중 화면 개편 설계

## 목표

ARAM 아수라장 탭에서 사용자가 챔피언을 고른 직후 다음 결정을 빠르게 내릴 수 있게 한다.

1. 실버·골드·프리즘 증강의 챔피언별 고정 TOP 3를 한 화면에서 비교한다.
2. 현재 제시된 증강이 고정 순위와 어떻게 겹치는지 바로 판정한다.
3. 신발을 포함한 최종 6슬롯 아이템 경로를 빠짐없이 확인한다.
4. AI 코칭은 일반론 대신 현재 챔피언·양 팀 조합·증강·6슬롯 빌드에 근거한 행동 지침을 준다.

## 데이터 계약

`MayhemAdvice`는 기존의 제시 증강 순위와 별도로 희귀도별 고정 추천을 보관한다.

- `silver`: Blitz 챔피언별 실버 증강 순서의 앞 3개
- `gold`: Blitz 챔피언별 골드 증강 순서의 앞 3개
- `prismatic`: Blitz 챔피언별 프리즘 증강 순서의 앞 3개
- 제시 증강을 입력해도 고정 TOP 3는 바뀌지 않는다.
- 고정 TOP 3는 Blitz 순서를 재채점하거나 섞지 않는다.
- 제시 증강 판정은 기존처럼 실제 입력된 증강만 대상으로 한다.

아이템 경로는 6슬롯을 목표로 한다.

- Blitz 완성 아이템 순서를 우선 사용한다.
- 중복 아이템을 제거하고 최대 6개까지 유지한다.
- Blitz 데이터가 6개보다 짧으면 챔피언 역할 기반 폴백에서 중복되지 않는 아이템을 보충한다.
- AI가 임의의 존재하지 않는 아이템을 만들어 채우지 않는다.
- 6개를 확보하지 못한 경우 빈 슬롯을 숨기지 않고 `상황 아이템 선택`으로 표시하며 이유를 함께 제공한다.

## 화면 구조

결과 화면의 정보 순서를 다음으로 고정한다.

### 1. 희귀도별 고정 TOP 3

최상단에 실버·골드·프리즘 3열 보드를 둔다. 각 열은 동일한 카드 구조를 사용한다.

- 희귀도 이름과 색상
- 1·2·3위 순위
- 증강 아이콘과 한글 이름
- 효과 요약
- 챔피언에게 맞는 이유 또는 Blitz 챔피언별 순위 근거

창 폭이 충분하지 않으면 열 내부 텍스트가 자연스럽게 줄바꿈되고, 가로 스크롤은 만들지 않는다.

### 2. 지금 제시된 증강 판정

입력된 증강만 별도의 압축 카드로 보여준다.

- 고정 TOP 3와 겹치면 해당 희귀도와 순위를 강조한다.
- 순위권 밖이면 카탈로그 등급과 챔피언 성향 판정을 표시한다.
- 알 수 없는 이름과 중복 입력은 이 영역에서만 경고한다.
- 입력이 없으면 `선택지가 보이면 입력하거나 LCU 자동 입력을 사용` 안내만 표시한다.

### 3. 6슬롯 완성 빌드

아이템을 3칸씩 두 줄로 배치한다.

- 첫 줄: 1·2·3슬롯
- 둘째 줄: 4·5·6슬롯
- 각 카드: 아이콘, 슬롯 번호, 아이템 이름, 선택 이유
- 신발은 별도 행으로 분리하지 않고 실제 최종 슬롯에 포함한다.

### 4. 이번 판 AI 작전

AI 결과는 다음 고정 순서로 표시한다.

1. 이번 판 승리 조건
2. 증강 선택 판단
3. 1~6슬롯 아이템 경로와 각 선택 이유
4. 한타 전·진입·마무리 행동 3단계
5. 상대 핵심 위협과 대응

화면에는 행동 중심 핵심 요약을 먼저 보여주고 전체 AI 원문은 아래에 둔다.

### 5. 보조 정보

조합 위협·시너지, 실전 팁, 데이터 출처는 핵심 영역 아래에 둔다. 기존 기능은 삭제하지 않는다.

## AI 품질 규칙

- 프롬프트에 현재 패치, 내 챔피언, 아군, 적군, 희귀도별 TOP 3, 현재 제시 증강, 6슬롯 기준 빌드를 전달한다.
- 답변은 반드시 6개 슬롯을 모두 다룬다.
- 모델이 슬롯을 누락하면 후처리가 검증된 메타·폴백 아이템으로 빈 슬롯을 보충한다.
- 동일 아이템 중복, 존재하지 않는 아이템명, `상황에 따라`만 적은 슬롯은 완성 슬롯으로 인정하지 않는다.
- 데이터가 없는 슬롯은 구체적인 역할을 가진 `상황 아이템 선택`으로 표시하고, 상대 조합에 따른 선택 기준을 적는다.
- 긴 배경 설명보다 지금 실행할 행동과 선택 이유를 우선한다.

## 오류와 폴백

- Blitz 챔피언 데이터가 없으면 희귀도 열마다 `추천 데이터 없음`을 명시한다.
- 아이콘 로드 실패 시 이름과 희귀도 배지가 남는다.
- AI 호출 실패 시 고정 TOP 3와 6슬롯 규칙 기반 브리핑은 그대로 유지한다.
- LCU나 Spectator 데이터가 없으면 챔피언 단독 기준 코칭으로 동작하며 조합 근거가 없음을 표시한다.

## 검증

- 단위 테스트: 희귀도별 TOP 3가 제시 증강과 독립적이고 Blitz 순서를 유지하는지 확인한다.
- 단위 테스트: 6슬롯 보충, 중복 제거, AI 응답의 6슬롯 후처리를 확인한다.
- GUI 테스트: 3열 증강 보드와 3×2 아이템 카드가 렌더링되는지 확인한다.
- 회귀 테스트: 제시 증강 추천·회피, LCU 자동 입력, 기존 ARAM 조합 분석이 유지되는지 확인한다.
- 수동 검증: 실제 앱에서 일반 폭과 좁은 폭의 아수라장 결과 화면을 캡처하고 CJK 줄바꿈·잘림·스크롤을 확인한다.

## 범위 밖

- 실시간 Blitz 웹 스크래핑 구조 변경
- 계정별 증강 승률 학습
- 서버 기반 사용자 통계 또는 커뮤니티 랭킹
- AI가 게임 중 실시간 상태를 연속 추적하는 채팅 기능
