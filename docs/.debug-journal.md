## Findings
### 2026-07-09 - strict encoding toggle
- Source: `PYTHONIOENCODING=cp949:strict python -m lol_coach --help`
- Value: exit 1, `UnicodeEncodeError: 'cp949' codec can't encode character '\u2014'`
- Interpretation: strict CP949 reproduces the Windows crash.
- Confirms: H1.

### 2026-07-09 - UTF-8 toggle
- Source: `PYTHONIOENCODING=utf-8:strict python -m lol_coach --help`
- Value: exit 0 and complete help text.
- Interpretation: changing only the stream encoding toggles the failure.
- Confirms: H1; refutes H2.

## Root cause (confirmed 2026-07-09)
- Mechanism: Click writes help through the process text stream. On Windows CP949, the U+2014 em dash in the command help cannot be encoded, so help handling raises before a command can run.
- Evidence: same source entry exits 1 under strict CP949 and 0 under strict UTF-8.
- Toggle proof: setting `PYTHONIOENCODING=utf-8:strict` makes the repro pass; restoring `cp949:strict` makes it fail.
- Fix scope: `src/lol_coach/cli.py` plus one subprocess regression test.

### 2026-07-09 - Riot host injection
- Source: prepared Requests request using platform `attacker.example#` and a fake token.
- Value: host `attacker.example`; `X-Riot-Token` header present.
- Interpretation: free-form platform input can redirect the authenticated request.
- Confirms: platform and region must be allowlisted before URL construction.
