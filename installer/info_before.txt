롤실전코치 — 개인 LoL 코칭 툴
================================

픽타임·듀얼 모니터용 개인 코치 앱입니다.

주요 기능
  · 소환사의 협곡 — 빠른 카운터픽 / 조합 상세 분석
  · ARAM 아수라장 — 증강 추천·회피 + 1~5코어 아이템
  · 최근 경기 복기 — 팀 조합, 승패 이유, 다음 판 교훈

필요 사항
  · 인터넷 연결 (Riot API · u.gg · Data Dragon)
  · Riot Developer API 키 (첫 실행 시 안내)

참고
  · API 키·설정은 사용자 폴더에 저장됩니다
    (%LOCALAPPDATA%\롤실전코치\.env)
  · 챔피언/아이템 아이콘은 처음 볼 때 받아 캐시합니다
  · 개인 개발 API 키는 보통 24시간마다 갱신이 필요합니다

비공식 개인 도구이며, Riot Games 와 무관합니다.
